ALU Architecture Explorer

An interactive guide exploring the refactoring of a MyHDL N-Bit ALU from an old design pattern to professional, synthesizable hardware architecture.

The Old Architecture

The previous design utilized a massive, single synchronous block. All operations were tied to the clock edge, forcing simple combinational logic to act like slow sequential logic.

Opcode + Data Inputs
@always(clock.posedge)
Giant if/elif chain
Operation Result
  • ❌ Magic Numbers: Used opcode == 8 instead of named states.
  • ❌ Wasted Registers: Simple logic like ADD consumed flip-flops.
  • ❌ Poor Scaling: Multi-cycle operations used manual busy flags.

The New Architecture

The new architecture splits logic by its physical hardware equivalent. It uses Enums for states, distinct combinational paths, and an output multiplexer.

Opcode + Data Inputs
@always_comb
ADD, SUB, AND, OR
@always(clk)
MUL, DIV States
@always_comb (Output MUX)
Selects result based on Opcode Enum
Operation Result
  • ✅ Enums: opcode == t_Op.ADD guarantees readability.
  • ✅ Combinational Speed: Basic math happens instantly in 0 cycles.
  • ✅ Explicit State Machine: Uses IDLE and CALC states cleanly.
Before: ALU_0.1.py (Snippet) Old Pattern 
# All operations trapped inside a clocked block
@always(clock_signal.posedge)
def logic():
    if opcode == 0:
        total = data_in_1 + data_in_2 + carry_in
        operation_result.next = total & full_mask
        
    elif opcode == 1:
        diff = (data_in_1 - data_in_2)
        operation_result.next = diff & full_mask
        
    # ... other bitwise logic ...
    
    elif opcode == 8: # What does 8 mean?
        if busy == 0:
            busy.next = 1
            # ...
After: ALU_0.1.py (Snippet) New Pattern 
# Combinational Logic (Instantly calculates)
@always_comb
def comb_logic():
    if opcode == t_Op.ADD:
        total = data_in_1 + data_in_2 + carry_in
        comb_result.next = total & full_mask
        
# Sequential State Machine (Multi-Cycle)
@always(clock_signal.posedge)
def seq_logic():
    if state == t_State.IDLE:
        if opcode == t_Op.MUL:
            state.next = t_State.CALC
            
# Physical Multiplexer for Output Routing
@always_comb
def out_mux():
    if opcode in (t_Op.MUL, t_Op.DIV):
        operation_result.next = seq_result
    else:
        operation_result.next = comb_result
